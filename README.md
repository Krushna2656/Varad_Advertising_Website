## Overview

**Varad Advertising** is a modern business website built to showcase professional signage, printing, branding, and outdoor advertising solutions.

The project focuses on creating an engaging digital presence for a local advertising business through a responsive interface, service presentation, and visual project showcase.

### Project Objectives

- Establish a professional digital identity for Varad Advertising.
- Showcase advertising services and signage solutions.
- Present business projects in an attractive visual format.
- Deliver a smooth experience across desktop and mobile devices.
- Create a maintainable frontend foundation for future improvements.

## Getting Started

### Prerequisites

Install the following tools:

- [Node.js](https://nodejs.org/) — a version compatible with the project's Vite setup
- npm
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/Krushna2656/Varad_Advertising_Website.git
```

### 2. Navigate to the Project

```bash
cd Varad_Advertising_Website
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Run the Development Server

```bash
npm run dev
```

Open the local address displayed in the terminal.

### 5. Create a Production Build

```bash
npm run build
```

The production build is generated inside the `dist/` directory.
